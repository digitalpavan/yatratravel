Mobile navigation

Below 1024px the header collapses to logo, Book Now and a menu button. The menu opens a full-height drawer from the right.

Behaviour

  1. Header stays sticky at 72px, so Book Now is always one tap away (hidden below 480px, where the drawer and sticky CTAs take over).
  2. The menu button has aria-expanded and aria-controls="drawer", and the drawer is a modal dialog.
  3. Opening the drawer moves focus to its first link. Tab stays inside it, and Esc, the close button or the backdrop closes it and returns focus to the menu button.
  4. The page behind it does not scroll. When closed, the drawer is inert, so screen readers skip it.
  5. The drawer footer always shows Book Now, WhatsApp, Call and opening hours, the three ways to reach the business.
  6. Links are 56px tall, and the current page is shown in gold.
  7. Motion is a 320ms slide, which is disabled under prefers-reduced-motion.
  8. The WhatsApp button floats on every page. On package pages a sticky price-and-Book bar sits at the bottom, and the floating button moves above it.

Accessibility checklist

Target: WCAG 2.1 AA on every page.

  • Text contrast ≥ 4.5:1 and UI/control borders ≥ 3:1, verified for every token pairing above.
  • Visible 3px focus ring on every interactive element: navy on light, light gold on dark.
  • "Skip to main content" link, landmarks (header/nav/main/footer) and one H1 per page.
  • Touch targets at least 44×44px. Buttons are 48px by default.
  • Forms: visible labels, autocomplete attributes, errors linked with aria-describedby, and an error summary that receives focus.
  • Colour is never the only signal. Status badges use words, and errors use an icon and text.
  • Photos have descriptive alt text, entered by the admin when uploading.
  • prefers-reduced-motion disables slides, shimmer and hover lifts.
  • Page zoom to 200% and 320px width work with no horizontal scroll.
